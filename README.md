## 命令行选项

| 选项 | 说明 |
|------|------|
| `-t, --threads <num>` | 设置线程数量（默认：4） |
| `-m, --move` | 启用移动模式而非复制 |
| `-v, --verbose` | 显示详细输出信息 |
| `-o, --overwrite` | 覆盖已存在的文件 |
| `-s, --skip` | 跳过已存在的文件 |
| `-h, --help` | 显示帮助信息 |
| `<source>` | 源文件或目录路径 |
| `<destination>` | 目标文件或目录路径 |
| `-V, --version` | 显示版本信息 |
